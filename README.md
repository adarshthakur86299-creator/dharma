# PROJECT DHARMA

A responsive, dependency-free practice app with JEE and SSC subject questions and calculation drills.

## Use the app

Open `index.html` in a browser. No installation, Python server, account, or API key is required. Subject question sets are bundled in `subject-questions.js`.

## Use on a phone

The easiest way is to open the deployed GitHub Pages link on your phone. For a private local setup, serve this folder from a computer on the same Wi-Fi and open that computer's address on the phone.

## Publish with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. After GitHub finishes deployment, open the Pages URL shown on that settings page. It will look like `https://adarshthakur86299-creator.github.io/dharma/`.

## Included practice

- 100 original multiple-choice questions each for JEE Mathematics, Physics, Chemistry and SSC Quantitative Aptitude, Reasoning, English, and General Awareness.
- Four answer choices, answer explanations, and quick-solving tips.
- No question repeats for a subject until all 100 have been shown; then a fresh round begins.
- Test history and no-repeat progress are saved in the current browser's local storage. Browser data is not shared between devices.
- Timed tests, untimed practice, calculation drills, and a progress dashboard.

These are original practice questions, not official exam papers.
